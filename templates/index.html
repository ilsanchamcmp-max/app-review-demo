Social Mention Monitor

Use case The communications team of Ilsan CHA Hospital uses this app to find public Threads and Instagram posts that mention the hospital, so staff can review public feedback and respond to it. The app only reads public content and the logged-in user's own account information. It does not post, message, or store any user content.

Two end-to-end flows are shown below. Each starts with the user logging in and granting permissions.

Flow 1: Threads

Log in with Threads, review the connected profile (threads_basic), then search public posts by keyword (threads_keyword_search).

Start →

Flow 2: Instagram

Log in with Facebook, choose a managed Page (pages_show_list), then search public Instagram posts by hashtag (Instagram Public Content Access).
